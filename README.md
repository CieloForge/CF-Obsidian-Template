# Obsidian Vault Template

A complete Obsidian vault template with pre-configured plugins, themes, and layouts to help you quickly replicate my Obsidian setup.

## Overview

This repository contains all the configuration files necessary to replicate my Obsidian vault's look and feel, including:

- **Community Plugins**: 25 carefully selected plugins for enhanced functionality
- **Themes**: 18 pre-installed themes (with Obsidianite as default)
- **Settings**: Pre-configured appearance, hotkeys, and workspace layouts
- **Layouts**: Optimized workspace configurations for different use cases

## Getting Started

### Prerequisites

- [Obsidian](https://obsidian.md/) installed on your system

### Installation Steps

1. **Download or Clone this Repository**
   - Download the ZIP file or clone the repository
   - Extract the contents to a new folder

2. **Open in Obsidian**
   - Open Obsidian
   - Click "Open folder as vault"
   - Select the folder containing the extracted files

3. **Restore Configuration**
   - Obsidian will automatically detect and apply the configuration
   - Plugins and themes should be pre-configured

## Configuration Files

### Key Configuration Files

- `.obsidian/appearance.json` - Theme and appearance settings
- `.obsidian/community-plugins.json` - List of enabled community plugins
- `.obsidian/core-plugins.json` - List of enabled core plugins
- `.obsidian/workspace.json` - Workspace layout configuration
- `.obsidian/hotkeys.json` - Keyboard shortcut mappings
- `.obsidian/plugins/` - Plugin data and settings
- `.obsidian/themes/` - Theme files

2. **Task Management**: Use the Tasks plugin for task tracking

4. **Organization**: Use Tag Wrangler for tag management

## Customization

### Changing Themes

1. Open Settings → Appearance
2. Select from the available themes in the "Themes" section
3. Enable or disable community themes

### Managing Plugins

1. Open Settings → Community Plugins
2. Disable or enable plugins as needed
3. Configure individual plugin settings

### Workspace Layouts

1. Use the workspace switcher to change between layouts
2. Customize layouts by dragging panes
3. Save layouts using the workspace manager

## Troubleshooting

### Plugins Not Loading

1. Check that Obsidian is updated to the latest version
2. Verify that all plugins are compatible with your Obsidian version
3. Reinstall any problematic plugins

### Theme Issues

1. Try switching to a different theme
2. Check for theme updates
3. Clear cache and restart Obsidian
